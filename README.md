# Knowledge Brief

내 지식 상태에 맞춰 읽을거리를 고르는 개인 학습 에이전트입니다. AI·개발 자료를 조사하고, 이미 아는 내용은 덜어내고, 모르는 기초를 함께 다룹니다.

[브리프 읽기](https://bswan0113.github.io/knowledge-brief/)

## 어떻게 고르나

- 지식 상태를 알고 있음·빈틈·오개념·미측정으로 기록합니다.
- 관련성, 새로움, 영향, 지속성, 긴급성, 신뢰도, 오개념 위험, 방치된 기간으로 자료를 평가합니다.
- 뉴스 유무와 관계없이 빈틈 보완 항목을 하루 한 건 넣습니다. 같은 계열이 3일 연속 선정되지 않도록 순환합니다.
- 7일 이상 재평가하지 않은 주제는 알립니다. 지식 상태를 다시 판단하는 일은 사용자와의 대화에서만 합니다.

## 실행 흐름

Windows 작업 스케줄러 → Claude Code → 자료 조사·선별 → 요약·용어 해설 → HTML·음성 생성 → GitHub Pages 게시 → 카카오 나에게 보내기

매일 22:00에 실행합니다. Python 감독기가 실행 기록, 중복 실행 방지, 타임아웃과 재개를 맡습니다. 놓친 회차를 복구하는 실행과 정규 실행은 별도 슬롯으로 관리합니다.

항목별 서브에이전트가 3줄 요약과 용어 해설을 만들고, 음성 파일도 생성합니다.

## 이 저장소

| 파일 | 내용 |
| --- | --- |
| `index.html` | 전체 브리프 목록 |
| `YYYY-MM-DD.html` | 날짜별 브리프 |
| `YYYY-MM-DD-2200.html` | 같은 날짜에 발행분을 구분한 브리프 |
| `audio/` | 음성 파일 |

각 브리프에는 주요 소식, 기초 보완, 짧게 훑을 레이더를 담습니다. 항목마다 사실·배경·내 지식과의 연결·학습 방향을 나누고, 3줄 요약과 용어 해설을 붙입니다.

이곳에는 발행 결과물을 공개합니다. 실행 코드와 개인 지식 프로필·로그는 포함하지 않습니다.

## 검증

전달 규칙을 검사하는 `brief_lint`, 선정 이력을 확인하는 `rotation_audit`, 반복 채점으로 점수 변동을 보는 `brief_judge`를 별도로 만들었습니다. 단위 테스트는 있지만 **야간 자동 실행에는 아직 연결하지 않았습니다.**

자료에 따라 2차 출처를 사용하며, 원문 확인 여부는 브리프에 표시합니다.
